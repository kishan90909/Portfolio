## 🚀 Overview

A modern and responsive personal portfolio built with **Next.js**, **React**, and **TypeScript**.

The portfolio presents professional information, technical skills, projects, achievements, hackathons, and certifications through a clean interface inspired by Apple's design style.

## 🛠️ Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Framer Motion
* Lucide React
* HTML5
* CSS3
* Git and GitHub
* Netlify

## 🚀 Getting Started

```bash
# Clone repository
git clone YOUR_GITHUB_REPOSITORY_URL

# Navigate to project
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open your browser and visit:

```bash
http://localhost:3000
```

## 📂 Portfolio Sections

The portfolio includes dedicated sections for professional introduction, technical skills, projects, certifications, achievements, hackathons, and contact information.

Project cards and other content sections use horizontal scrolling to provide a clean browsing experience across different screen sizes.

## 🌐 Deployment

The project is deployed using **Netlify**.

To deploy the project, connect the GitHub repository to Netlify and configure the build settings according to the project setup.

New changes pushed to the connected GitHub repository can trigger automatic deployments.
